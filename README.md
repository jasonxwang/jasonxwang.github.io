## Run locally

From the repository root, install Jekyll and Bundler if needed, then run:

```bash
bundle exec jekyll serve
```

Open the local URL printed by Jekyll, usually `http://localhost:4000`.

## Open the calculator

Visit the landing page and select **Open the calculator**, or open the calculator directly:

`gas-vs-ev-cost-calculator.html`

## Deployment

GitHub Pages reads the repository's Jekyll configuration and serves the site from the default branch.
